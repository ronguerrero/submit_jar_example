# submit_jar_example

### How to run   
1) Compile:  mvn clean package  
2) Upload: Upload to Volume  
3) Modify YAML config - job.yaml
4) Create Workflow Job --> Click 3 vertical dots --> Edit as YAML  
5) Copy paste modified YAML config  
6) Click on Run Now  


Reference: https://learn.microsoft.com/en-us/azure/databricks/jobs/how-to/use-jars-in-workflows
